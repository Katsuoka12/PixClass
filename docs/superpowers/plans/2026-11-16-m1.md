# M1 Implementation Plan

**Goal:** Implement the project structure and secure authentication specified in AGENTS.md.

**Spec:** ../../../AGENTS.md (user supplied implementation specification).

**Architecture:** Independently installed Express REST API and Nuxt UI communicate over HTTP only. mysql2 prepared statements store users in MariaDB. JWT cookies expire after 15 minutes; current account status and role are loaded on every authenticated request.

**Constraints:** Strict TypeScript, Thai UI, npm, no ORM or cross-project imports, zod validation, scoped CORS and CSRF protection. Complete and report M1 before M2. Commit once for this milestone as required by AGENTS.md.

## Review focus

1. Public registration must reject role injection and bcrypt input beyond 72 UTF-8 bytes.
2. Suspended accounts and stale JWT roles must not retain access.
3. Foreign/missing origins must not mutate cookie-authenticated state.
4. Database failures and duplicate registration races must return safe consistent errors.
5. SSR must forward cookies while the UI denies incorrect roles and restores auth after reload.
